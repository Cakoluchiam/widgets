YouTube → Winamp

Turn a YouTube Music playlist into an .m3u8 Winamp can crossfade.

1 Get the playlist out of YouTube

Works for any playlist you can see, private ones included, because it runs inside your already-signed-in tab. Nothing is sent anywhere.

  1. Open your playlist on music.youtube.com (or youtube.com).
  2. Press F12 → Console.
  3. First time only: type allow pasting and press Enter — Chrome and Edge block console pastes until you do.
  4. Paste the snippet below and press Enter. It scrolls the whole list, then copies the result.
  5. Come back here and paste into the box.

3 Point it at your music

    

      Winamp plays files on your disk, so each track needs a real path. Give it a listing of your
      music folder and every track gets matched automatically. The matches are remembered between
      visits; the folder index itself is not, so re-paste the listing if you want to match again
      later.

Turning on crossfade in Winamp

      
    

    

      

        Crossfading lives in Winamp's output plugin, not in the playlist — so it is a
        one-time setup that then applies to every playlist you load.
      

      
    
        
  1. Press Ctrl+P for Preferences.
    2. 
        
  2. In the left tree open Plug-ins → Output.
    3. 
        
  3. Select Nullsoft DirectSound Output (out_ds.dll) and click
          Configure. This matters: the older WaveOut plugin cannot crossfade at all.
    4. 
        
  4. Open the Fading tab. Each action gets its own setting:
          
      
            
    • on end of song — tick Enabled and Use custom fade time,
              then set something like 3000 ms. This is the one that actually
              crossfades one track into the next.
      • 
            
    • on start — leave disabled, or tracks fade in on top of the outgoing
              one and the overlap sounds muddy.
      • 
            
    • on manual song change — enable if you want skips to blend too.
      • 
            
    • on pause/stop — a short 200–500 ms fade avoids clicks.
      • 
          
    
        
    5. 
        
  5. On the Buffering tab, raise the buffer length. More buffer gives the
          plugin room to hold both tracks; the maximum is 20000 ms.
    6. 
        
  6. Click OK and restart playback.
    7. 
      

      

        Exact labels shift a little between Winamp versions, but the Fading tab and its
        per-action rows have been in the DirectSound plugin for a very long time.
      

      
If it still doesn't blend

      
    
        
  • Crossfade needs the next file ready in advance, so it works on local files — not on
          streamed URLs.
    • 
        
  • Any track in the playlist that Winamp cannot find is skipped instantly, which reads as a
          gap. Step 3 above is what stops that happening.
    • 
        
  • Gapless-encoded albums may still sound abrupt if the fade time is longer than the
          silence at the track edges. Try 2000 ms.
